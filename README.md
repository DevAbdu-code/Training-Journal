## 📌 About This Journal

Welcome to my **Cyber Security Learning Journal** – a comprehensive documentation of my journey through the INSA Weekend Cyber Security Training program. This repository serves as my personal knowledge base, containing detailed notes, practical examples, and hands-on exercises covering various cybersecurity domains.

### 🎯 Purpose
-  **Document** all concepts learned during training
-  **Practice** and apply theoretical knowledge
-  **Track** progress and identify areas for improvement
-  **Share** insights with the cybersecurity community
-  **Create** a personal reference library for future use

### 🎓 Training Program
- **Institution:** INSA (Information Network Security Agency)
- **Program:** Weekend Cyber Security Training
- **Status:** 🔄 In Progress
- **Focus:** Foundational to Advanced Security Concepts

## 📖 How to Use This Journal

### For Beginners
1. Start with `Linux_Basics_Note.md` for foundational knowledge
2. Progress to `Networking_Fundamentals.md`
3. Explore tools with `Nmap_Mastery_Notes.md`
4. Apply concepts with security-focused notes

### For Advanced Learners
1. Review the OWASP Top 10 notes
2. Practice with brute force enumeration techniques
3. Study Windows Event Logs analysis
4. Combine tools for comprehensive assessments
